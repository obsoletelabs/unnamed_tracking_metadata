Supported field typesstring integer number boolean date url enum

Each field has key, label and type; optional flags are required and multiple. Enum fields also need an options array.

Example schema
[
  {"key":"genres","label":"Genres","type":"string","multiple":true},
  {"key":"edition","label":"Edition","type":"enum","options":["standard","deluxe","complete"]},
  {"key":"player_count","label":"Maximum players","type":"integer"},
  {"key":"is_remake","label":"Is a remake","type":"boolean"}
]
