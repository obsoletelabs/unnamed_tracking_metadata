For applications

A small, usable REST API

Public read endpoints and token-authenticated catalogue writes.

Open interactive API docs ↗
GET
/api/v1/games?q=hollow

Search and list catalogue records. Supports q, limit and offset.

Public
GET
/api/v1/games/{id}

Retrieve one record by its canonical ID.

Public
POST
/api/v1/games

Add a record using JSON and an Authorization: Bearer … header.

API key
Example request
curl "http://localhost:8000/api/v1/games?q=hollow" \
  -H "Accept: application/json"

curl -X POST "http://localhost:8000/api/v1/games" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"title":"Tunic","developer":"TUNIC Team","release_year":2022,"description":"An isometric adventure."}'

The prototype does not yet enforce rate limits or beta quotas. Do not expose it to the public internet as a production service.
