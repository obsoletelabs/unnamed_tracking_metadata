# API reference

_Generated by `tools/gen_docs.py` from the code. Do not edit by hand._

Base path `/api/v2`. Send `Authorization: Bearer <token>`. Scopes: `read`, `contribute`, `curate`, `sync`, `admin` (`admin` implies all). Endpoints marked **public** need no token. Errors are `{"error": {"code", "message"}}`; validation errors are `422`; limits return `429` with `Retry-After`.

## ops

| Method | Path | Scope | What it does |
| --- | --- | --- | --- |
| `GET` | `/health` | public | Liveness: the process is up. |
| `GET` | `/ready` | public | Readiness: the database answers and its schema is current (503 otherwise). |
| `GET` | `/schema` | public | Media types and custom fields this node describes (public ones only). |
| `GET` | `/site` | public | Name, theme, navigation, role, registration and email policy of this node. |

## read

| Method | Path | Scope | What it does |
| --- | --- | --- | --- |
| `GET` | `/artwork/{art_id}/image` | read | One image: its cached bytes, or a redirect to the original public address while it is not cached. |
| `GET` | `/games` | read | Search records by title (`q`, optional `type`, `limit`). Includes `custom` values. |
| `GET` | `/games/{cid}` | read | One record. Follows merge redirects (`redirected_from`). ETag = id-version. |
| `GET` | `/games/{cid}/achievements` | read | Merged achievement list: name, description, kind, tier, points, icons, global percent. Hidden ones are redacted unless `reveal=all` or `reveal=<id>,<id>` is sent with a signed-in user's token or a curator token. No per-user progress. See [Achievements](achievements.md). |
| `GET` | `/games/{cid}/artwork` | read | Artwork by trust and priority, plus the best image per kind; `media_url` once cached, and `image_url` always. |
| `GET` | `/games/{cid}/explain` | read | Which source and rule produced each field (provenance). |
| `GET` | `/media/{digest}` | read | A cached, verified image. Immutable; `nosniff`. |
| `POST` | `/resolve` | read | Batch (max `max_resolve`): store ids / titles to canonical ids with method and confidence. Read-only. |

## federation

| Method | Path | Scope | What it does |
| --- | --- | --- | --- |
| `GET` | `/sync/changes` | sync | Signed entries after `since`; optional `node_id` selects a retained original authority feed. |
| `GET` | `/sync/digest` | sync | Digest of the replicated observations of this node's feed (or a retained one with `node_id`), for `atlas sync reconcile`. Observations only; cached up to 60 s (`cached_seconds`). |

## admin

| Method | Path | Scope | What it does |
| --- | --- | --- | --- |
| `GET` | `/status` | admin | Role, feed head, replication cursors, the number of feed entries that failed to apply and the named heads per upstream. |
| `GET` | `/sync/failures` | admin | Mirrored feed entries that could not be applied and still need attention: parked (need a newer release) or quarantined. |
| `POST` | `/sync/failures/retry` | admin | Retry failed mirrored entries now, whatever the automatic attempt count. |
| `GET` | `/sync/status` | admin | Protocol versions, named heads (observed, downloaded, verified, applied), parked and quarantined entries per upstream, and the protocol each follower last spoke. |
| `GET` | `/tokens` | admin | List API tokens. |
| `POST` | `/tokens` | admin | Create a token; the secret is returned once. |
| `DELETE` | `/tokens/{tid}` | admin | Revoke a token. |
