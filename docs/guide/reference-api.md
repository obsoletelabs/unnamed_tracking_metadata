# API reference

_Generated by `tools/gen_docs.py` from the code. Do not edit by hand._

Base path `/api/v2`. Send `Authorization: Bearer <token>`. Scopes: `read`, `contribute`, `curate`, `sync`, `admin` (`admin` implies all). Endpoints marked **public** need no token. Errors are `{"error": {"code", "message"}}`; validation errors are `422`; limits return `429` with `Retry-After`.

## ops

| Method | Path | Scope | What it does |
| --- | --- | --- | --- |

| `GET` | `/ready` | public | Readiness: the database answers. |
| `GET` | `/schema` | public | Media types and custom fields this node describes (public ones only). |
| `GET` | `/site` | public | Name, theme, navigation, role, registration and email policy of this node. |

## read

| Method | Path | Scope | What it does |
| --- | --- | --- | --- |
| `GET` | `/games` | read | Search records by title (`q`, optional `type`, `limit`). Includes `custom` values. |
| `GET` | `/games/{cid}` | read | One record. Follows merge redirects (`redirected_from`). ETag = id-version. |
| `GET` | `/games/{cid}/achievements` | read | Merged achievement list: name, description, icon, hidden, global percent. No per-user progress. |
| `GET` | `/games/{cid}/artwork` | read | Artwork by trust and priority, plus the best image per kind; `media_url` once cached. |
| `GET` | `/games/{cid}/explain` | read | Which source and rule produced each field (provenance). |
| `GET` | `/media/{digest}` | read | A cached, verified image. Immutable; `nosniff`. |
| `POST` | `/resolve` | read | Batch (max `max_resolve`): store ids / titles to canonical ids with method and confidence. Read-only. |

## curate

| Method | Path | Scope | What it does |
| --- | --- | --- | --- |
| `PUT` | `/games/{cid}/achievements` | curate | Replace the curated achievement set for a record. |
| `PUT` | `/games/{cid}/artwork` | curate | Replace the curated artwork set for a record. |
| `PUT` | `/games/{cid}/custom` | curate | Set or clear curated custom-field values. |

| `PUT` | `/games/{cid}/locks/{field}` | curate | Pin a field value; it beats every merged value. |
| `POST` | `/games/{cid}/merge` | curate | Merge a record into another (leaves a redirect). |

| `POST` | `/observations/{oid}/detach` | curate | Split one source record off onto its own record. |

| `POST` | `/review/{rid}/dismiss` | curate | Mark a review item as not a duplicate. |
| `POST` | `/review/{rid}/merge` | curate | Resolve a review item by merging into one of its candidates. |
