    Admin settings¶

    Generated by tools/gen_docs.py from the code. Do not edit by hand.

    These can be changed live in Admin → Settings without restarting. Each change is recorded in the audit log, and Use default returns a setting to its environment value.

    Branding¶

    Setting Type Default Notes
    Site name (app_name) text Atlas Shown in the header, page titles and emails.
    Tagline (tagline) text Game metadata, merged and sourced One line under the title on the home page.
    Footer text (footer_text) text Community metadata. Contributions are CC0. Plain text shown in the footer.
    Accent colour (dark theme) (accent_color) colour #6aa8ff
    Accent colour (light theme) (accent_color_light) colour #1f6fe0
    Theme (default_theme) auto / dark / light auto 'auto' follows each visitor's system setting.
    Navigation links (nav_links) list of links — One per line: Label | address. Addresses may be /paths or https:// links.

    Community¶

    Setting Type Default Notes
    Registration (registration) open / closed open Whether new people can create accounts.
    Email verification (email_verification) off / optional / required — Whether a verified address is needed to contribute. Empty = by node role (authorities require it).
    Auto-apply from reputation (auto_approve_reputation) number (0–1000000) 50 Users at or above this reputation have their changes applied immediately. 0 disables.
    Reviewer from reputation (curator_reputation) number (0–1000000) 500 Reputation that grants review rights. 0 = only people you promote.
    Pending proposals per user (max_pending_proposals) number (1–1000) 20
    Daily proposals, new users (new_user_daily_proposals) number (1–10000) 10
    Daily proposals, trusted users (trusted_daily_proposals) number (1–100000) 100
    Community artwork per game (community_art_cap) number (1–200) 50
    Comments (comments_enabled) on/off True Let verified users discuss games and proposals.
    Comments per user per day (comment_daily_limit) number (1–10000) 30
    Reputation needed to comment (comment_min_reputation) number (0–1000000) 0
    Reports that auto-hide a comment (comment_autohide_reports) number (1–100) 3
    Personal lists and follows (lists_enabled) on/off True
    Lists per user (max_lists_per_user) number (1–500) 20
    Games per list (max_list_items) number (1–100000) 2000
    Follows per user (max_follows) number (1–100000) 500

    Federation¶

    Setting Type Default Notes
    Act as a sign-in provider (OIDC) (oidc_provider_enabled) on/off False Lets other nodes you register under Admin → Sign-in sharing let your users sign in with their account here.
    Adopt the upstream media types and fields (inherit_schema) on/off True Mirrors and local nodes copy the authority's custom fields; yours always take precedence.

    Security¶

    Setting Type Default Notes
    Minimum password length (password_min_length) number (8–64) 10
    Sign-in lifetime (days) (session_ttl_days) number (1–90) 14
    API requests per minute per token (rate_limit_per_minute) number (1–100000) 600
    Largest observation batch (max_batch) number (1–5000) 1000
    Largest resolve batch (max_resolve) number (1–5000) 200

    Matching¶

    Setting Type Default Notes
    Auto-match confidence (percent) (auto_match_threshold) number (50–100) 8500 Matches at or above this are merged automatically.
    Review confidence (percent) (review_threshold) number (0–100) 6000 Weaker matches below the auto threshold but above this open a duplicate review.

    Artwork¶

    Setting Type Default Notes
    Download and cache artwork (media_cache_enabled) on/off True
    Largest image (bytes) (media_max_bytes) number (1024–52428800) 10485760
