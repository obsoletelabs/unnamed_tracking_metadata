    Environment variables¶

    Generated by tools/gen_docs.py from the code. Do not edit by hand.

    Every setting is read from an environment variable named ATLAS_<NAME> (or from a .env file). Settings marked live can also be changed at runtime in Admin → Settings; the environment value is then only the default.

    Node¶

    Variable Default Meaning
    ATLAS_ROLE local authority (the source of truth; publishes the signed change feed), mirror (replicates an authority) or local (a private node that caches providers and may replicate).
    ATLAS_DATABASE_URL sqlite:///./atlas.db SQLAlchemy URL. sqlite:///./atlas.db for local nodes; postgresql+psycopg://user:pw@host/db for authorities (required in production).
    ATLAS_PUBLIC_URL http://localhost:8000 The address people use to reach this node. Used in emails, OIDC and links. Must be https:// in production.
    ATLAS_ENVIRONMENT dev dev shows API docs at /docs and relaxes production checks; production enforces HTTPS, PostgreSQL for authorities and an explicit initial administrator.
    ATLAS_INITIAL_ADMIN — Username that becomes the website administrator when it registers. If unset, the first account to register is the administrator (production with open registration refuses to start without it).
    ATLAS_BOOTSTRAP_ADMIN_TOKEN — 32+ random characters. Becomes an admin API token while set; removing it revokes it. Use it to create the first real tokens.
    ATLAS_SECRET_KEY — Encrypts secrets stored in the database (peer tokens, OIDC client secrets). Generate one with atlas secret-key. Losing it makes those secrets unreadable.
    ATLAS_AUTO_MIGRATE — Run database migrations on start. Default: on for SQLite, off otherwise. With several replicas set false and run atlas migrate as a job.

    Federation¶

    Variable Default Meaning
    ATLAS_UPSTREAM_URL — Address of an upstream node to replicate from (simple single-upstream setups; more can be added under Admin → Peers).
    ATLAS_UPSTREAM_TOKEN — API token (scopes read, sync) for upstream_url.
    ATLAS_TRUSTED_KEYS — JSON object {"<node id>": "<base64 public key>"} of upstream nodes whose signed feed you trust. Required when upstream_url is set. Get the values from atlas node on the upstream.
    ATLAS_SYNC_INTERVAL_SECONDS 60 How often to pull from peers (minimum 5).
    ATLAS_SYNC_BATCH_SIZE 500 Feed entries fetched per request.
    ATLAS_INHERIT_SCHEMA true Adopt the upstream authority's media types and custom fields (yours always take precedence). Editable in Admin → Settings. live
    ATLAS_OIDC_PROVIDER_ENABLED false Let other nodes and the Tracking App sign users in with accounts on this node (OpenID Connect). Editable in Admin → Settings. live

    Matching¶

    Variable Default Meaning
    ATLAS_AUTO_MATCH_THRESHOLD 0.85 Confidence (0.5–1.0) at or above which an incoming record is merged into an existing one automatically. Editable as a percentage in Admin → Settings. live
    ATLAS_REVIEW_THRESHOLD 0.6 Confidence below the auto threshold but above this opens a possible-duplicate review. live
    ATLAS_SOURCE_TRUST {'curator': 100, 'manual': 90, 'community': 85, 'igdb': 70, 'steam': 65, 'gog': 60, 'rawg': 50} JSON object of source name → trust weight used to choose between conflicting values (higher wins). Reserved names need the curate scope to submit.
    ATLAS_DEFAULT_TRUST 40 Trust for sources not listed in source_trust (apps and plugins submitting data).
    ATLAS_REDISTRIBUTABLE_SOURCES ['community', 'curator', 'manual'] Sources whose curated observations are published on the change feed. Provider data (Steam, IGDB…) is never federated.

    Limits¶

    Variable Default Meaning
    ATLAS_MAX_BATCH 1000 Largest observation batch accepted by the API. live
    ATLAS_MAX_RESOLVE 200 Largest /resolve batch. live
    ATLAS_RATE_LIMIT_PER_MINUTE 600 API requests per token per minute (unauthenticated callers get 60 per address). live
    ATLAS_MAX_BODY_BYTES 2000000 Largest request body accepted.

    Providers¶

    Variable Default Meaning
    ATLAS_STEAM_ENABLED true Use Steam's public store API.
    ATLAS_RAWG_API_KEY — Enables the RAWG provider.
    ATLAS_IGDB_CLIENT_ID — Twitch client id; with the secret enables the IGDB provider.
    ATLAS_IGDB_CLIENT_SECRET — Twitch client secret for IGDB.
    ATLAS_PROVIDER_TTL_SECONDS 604800 How long a provider answer is cached.
    ATLAS_PROVIDER_NEGATIVE_TTL_SECONDS 86400 How long “not found” is cached.
    ATLAS_STEAM_API_KEY — Steam Web API key. Without it achievements have global percentages only (no names).

    Artwork¶

    Variable Default Meaning
    ATLAS_MEDIA_DIR ./media Directory for cached images (content-addressed). Mount a volume here.
    ATLAS_MEDIA_CACHE_ENABLED true Download and verify artwork in the background. Editable in Admin → Settings. live
    ATLAS_MEDIA_MAX_BYTES 10485760 Largest image accepted (bytes). live
    ATLAS_MEDIA_MAX_PIXELS 40000000 Largest image by pixel count (decompression-bomb guard).
    ATLAS_MEDIA_CACHE_BATCH 10 Images processed per background pass.
    ATLAS_MEDIA_ALLOWED_HOSTS — If non-empty, only these hostnames may be downloaded from. Always public addresses only.

    Branding¶

    Variable Default Meaning
    ATLAS_APP_NAME Atlas Site name. Editable in Admin → Settings. live
    ATLAS_TAGLINE Game metadata, merged and sourced Home page line. Editable in Admin → Settings. live
    ATLAS_FOOTER_TEXT Community metadata. Contributions are CC0. Footer text. Editable in Admin → Settings. live
    ATLAS_ACCENT_COLOR #6aa8ff Accent colour, dark theme. Editable in Admin → Settings. live
    ATLAS_ACCENT_COLOR_LIGHT #1f6fe0 Accent colour, light theme. Editable in Admin → Settings. live
    ATLAS_DEFAULT_THEME auto auto, dark or light. Editable in Admin → Settings. live
    ATLAS_LOGO_HASH — Set by uploading a logo in Admin → Settings; not meant to be set by hand. live
    ATLAS_NAV_LINKS — Extra menu links. Editable in Admin → Settings. live

    Email¶

    Variable Default Meaning
    ATLAS_MAIL_BACKEND outbox outbox stores messages for admins to read and sends nothing; smtp delivers. live
    ATLAS_SMTP_HOST — SMTP server. live
    ATLAS_SMTP_PORT 587 587 (STARTTLS) or 465 (implicit TLS). live
    ATLAS_SMTP_USER — SMTP username (empty for none). live
    ATLAS_SMTP_PASSWORD — SMTP password. Only ever read from the environment, never stored in the database.
    ATLAS_SMTP_STARTTLS true Upgrade the connection with STARTTLS. live
    ATLAS_MAIL_FROM atlas@localhost From address, e.g. Atlas <noreply@example.org>. live

    Community¶

    Variable Default Meaning
    ATLAS_EMAIL_VERIFICATION — off, optional or required. Unset = by role: authorities require a confirmed address to contribute, other nodes do not. live
    ATLAS_REGISTRATION open open or closed. live
    ATLAS_SESSION_TTL_DAYS 14 Sign-in lifetime. live
    ATLAS_AUTO_APPROVE_REPUTATION 50 Reputation from which a user's changes apply immediately (0 disables). live
    ATLAS_CURATOR_REPUTATION 500 Reputation that grants review rights (0 = only people you promote). live
    ATLAS_MAX_PENDING_PROPOSALS 20 Pending proposals per user. live
    ATLAS_NEW_USER_DAILY_PROPOSALS 10 Proposals per day for users who are not trusted yet. live
    ATLAS_PASSWORD_MIN_LENGTH 10 Minimum password length (8–64). live
    ATLAS_TRUSTED_DAILY_PROPOSALS 100 Proposals per day for trusted users (reviewers are not capped). live
    ATLAS_COMMUNITY_ART_CAP 50 Community-contributed images per game. live
    ATLAS_COMMENTS_ENABLED true Comments on games and proposals. live
    ATLAS_LISTS_ENABLED true Personal lists and follows. live
    ATLAS_COMMENT_DAILY_LIMIT 30 Comments per user per day. live
    ATLAS_COMMENT_MIN_REPUTATION 0 Reputation needed to comment. live
    ATLAS_COMMENT_AUTOHIDE_REPORTS 3 Open reports from distinct users that hide a comment pending review. live
    ATLAS_MAX_LISTS_PER_USER 20 Lists per user. live
    ATLAS_MAX_LIST_ITEMS 2000 Games per list. live
    ATLAS_MAX_FOLLOWS 500 Follows per user. live
