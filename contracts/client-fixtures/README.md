# Atlas client fixtures (client-api 1.0, seed `connectors-v1`)

Generated by Atlas `tools/export_client_fixtures.py` (CONTRACT-C15 §9.3); do not edit by hand. Regenerate with
`python tools/export_client_fixtures.py` in the Atlas repository.

Every record is **synthetic**: the `connectors-v1` catalogue (`atlas.client_seed`, also `atlas seed --fixture connectors-v1`)
invents its titles, people, companies, ids (namespaces `fixturegames`, `fixturebooks`) and ISBNs (valid check digits
only). No provider data. Dedicated to the public domain (CC0 1.0), like the rest of the Atlas `contracts/` folder.

| Path | What it is |
|---|---|
| `games/`, `books/` | Answers recorded from a real Atlas (`origin: recorded` in `MANIFEST.json`) |
| `pairing/` | Pairing answers; the code, poll token and QR are placeholders |
| `forward-compat/` | A recorded record with unknown members and values added (`origin: derived`) |
| `resolve/` | The C4 `/resolve` contract and its pin, copied from Atlas `tests/fixtures` |
| `MANIFEST.json` | Request, status, headers and origin of every file |
| `SHA256SUMS` | sha256 of every file (LF bytes) |

Normalised for determinism: Atlas ids come from a counter, timestamps read `2026-01-01T00:00:00+00:00`, the node id is `0123456789abcdef`
and the local change log epoch `fedcba9876543210`.
